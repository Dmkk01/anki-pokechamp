# Pokechamp Anki Decks

Anki study decks built from Pokechamp's structured Pokemon Champions data.

## Purpose

This repository stores generated Anki packages for learning Pokemon Champions information from Pokechamp, including Pokemon identity, typing, abilities, base stats, and speed comparisons.

The decks are meant for practical study while playing: quick recognition, stat memory, ability recall, and links back to the relevant Pokechamp pages for more context.

## Contents

- `decks/` - ready-to-import `.apkg` files for Anki.

## Decks

- `pokechamp-pokemon-identity.apkg` - image/name recognition, typing, and Pokemon abilities.
- `pokechamp-pokemon-stats.apkg` - base stat questions and speed comparisons.
- `pokechamp-abilities.apkg` - ability effects and Pokemon users.

## Usage

Open Anki and import the `.apkg` files from `decks/`.

These decks are free to use for personal study. The data comes from Pokechamp and is focused only on Pokemon Champions.

## Source

Decks are generated from the local Pokechamp project using its Anki build endpoint. Card backs include links to `https://pokechamp.io` so you can open the related Pokemon or ability page from Anki.

The raw source export and standalone media files are not published here; this repository is intended to distribute the usable Anki deck packages only.
